# Student Planner React

A comprehensive student planner application built with React + Vite. This application helps students manage their studies, plan their time efficiently, track progress, and utilize AI-powered features for a better learning experience. 

## Features

This planner incorporates a wide array of tools including:

- **Core Planning**: Daily/weekly schedules, drag-and-drop timetable, priority tagging, and semester planning.
- **Task & Progress Tracking**: Progress bars, streak tracking, missed task tracking, and performance trend graphs.
- **Focus & Productivity Tools**: Pomodoro timer, deep work mode, focus analytics, and ambient sounds integration.
- **AI & Smart Features**: AI study plan generator, smart revision planner, AI quiz generation, and personalized schedule optimization (powered by Google GenAI).
- **Notes & Learning Tools**: Built-in rich text editor, flashcards, spaced repetition, mind maps, and note linking.
- **Exams & Practice**: Mock test scheduling, mistake logs, accuracy tracking, and exam simulation.
- **Motivation & Gamification**: XP points, daily goals, leaderboards, and study streaks.
- **Utilities**: Dark/light mode, cross-device sync, and offline mode.

## Tech Stack

- **Frontend Framework**: React 19
- **Build Tool**: Vite
- **Routing**: React Router v7
- **Charts/Analytics**: Chart.js
- **AI Integration**: Google GenAI
- **State Management**: React Context API

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)

### Installation

1. Open the project folder `StudentPlanner`.
2. Install the dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open your browser and navigate to the local URL provided by Vite (usually `http://localhost:5173`).

### Building for Production

To create a production build, run:

```bash
npm run build
```

You can preview the built application with:

```bash
npm run preview
```
